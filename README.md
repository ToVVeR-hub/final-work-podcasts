# VibeCast Studio

Учебный React-проект — аудиоплеер с каталогом треков, избранным и адаптивным интерфейсом  
(десктоп + мобильная версия).

## Функциональность

- Прослушивание аудиофайла (т.к предоставленый сервер не возвращет ссылки на треки, то используется тестовый для проверки функциональности плеера)
- Управление плеером с клавиатуры (space, стелочки, "N" и "P")
- Управление плеером через его UI (перемотка, следующий/предыдущий трек, repeat (all или one), shuffle pause/play, добавление в избранное, уровень громкость, mute)
- Регистрация и авторизациия
- Просмотр списка треков (На десктобе - таблица с пагинацией, на мобильном виде список карточек с прокруткой)
- Модальное окно карточки трека (Кнопка "...")
- Страница пользователя (Переход через user menu в правом верхем углу)

## Структура проекта (сокращённо)

src/
- app/ # Инициализация приложения
- pages/ # Страницы (Tracks, Login, Profile)
- widgets/ # Крупные UI-блоки (Player, Header)
- features/ # Фичи (auth, favorites)
- entities/ # Бизнес-сущности (track, player)
- shared/ # Общие утилиты, иконки, API
- styles/ # Глобальные стили
- main.tsx
